# Splash artwork

`splash.png` is the new startup artwork supplied by Luca Iannelli on 2026-10-29 as `Tabboz Simulator_ Edizione Windows 10_11.png` for this Windows port. The original PNG is preserved without modification (1448 × 1086).

It is embedded as native resource 5001 and displayed proportionally through Windows GDI+, without cropping. Original in-game character artwork remains in the upstream bitmap resources.

`app.ico` and `app-icon.png` were also supplied by Luca Iannelli. The ICO contains 16, 24, 32, 48, 64, 96, 128 and 256 pixel variants and is used for the executable, taskbar/windows and installer.
