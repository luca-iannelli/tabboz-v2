# Roadmap

1. Original assessment and design — completed; REA evidence retained, C/Win32 approach selected and design approved by user.
2. Native x64 application — completed; original gameplay retained, euro display, native resources/controls, safe persistence, supplied splash/icon, independent assessment and regression verification.
3. Distribution and validation — completed; installer and portable package built, Windows 11 install/launch/upgrade/uninstall and data preservation checked, native artifacts inspected with REA.

Follow-up verification opportunities: actual Windows 10 runtime and physical mixed-DPI monitors. New character artwork was discussed as a possible later change and is not part of this completed port.
